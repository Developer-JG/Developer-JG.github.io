# 이미지 폴더 구조

이 폴더에는 웹사이트에 사용되는 이미지 파일들이 저장됩니다. 이미지를 교체하려면 동일한 파일명으로 새 이미지를 업로드하세요.

## 폴더 구조

- `/images/profile.jpg` - 프로필 이미지 (홈페이지와 About 페이지에 사용)
- `/images/research/` - 연구 관련 이미지
  - `paper1.jpg` - 첫 번째 논문 관련 이미지
  - `paper2.jpg` - 두 번째 논문 관련 이미지
- `/images/leadership/` - 리더십 활동 관련 이미지
  - `activity1.jpg` - 활동 사진 1
  - `activity2.jpg` - 활동 사진 2

## 이미지 교체 방법

1. 동일한 파일명으로 새 이미지를 준비합니다.
2. GitHub 저장소의 해당 폴더에 이미지를 업로드합니다.
3. 변경사항을 커밋하고 푸시하면 GitHub Actions가 자동으로 웹사이트를 다시 빌드하고 배포합니다.

## 이미지 크기 권장사항

- 프로필 이미지: 최소 400x400 픽셀, 정사각형 비율 권장
- 연구 이미지: 최소 800x400 픽셀, 16:9 비율 권장
- 활동 이미지: 최소 800x400 픽셀, 16:9 비율 권장

모든 이미지는 웹 최적화를 위해 JPG 또는 WebP 형식으로 저장하고, 파일 크기는 500KB 이하로 유지하는 것이 좋습니다.
